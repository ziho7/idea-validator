# v0.1.0 质量检查记录

检查日期：2026-10-10。以下记录区分代码检查、行为试用与真实案例；不提供准确率或商业成功率承诺。

## 自动化检查

- Skill frontmatter、命名和入口结构通过 skill-creator 的 quick_validate 检查。
- Python unittest 共 10 项：合法台账、未知日期、重复编号、不存在的假设引用、摘要/不可访问线索、错误日期、付费行为字段、异常嵌套类型、空研究、重复 URL，以及 CLI 退出码。
- 真实案例 evidence.json 的 7 条记录通过结构检查。
- GitHub Actions 运行同一测试集和真实案例台账校验。

校验器只检查数据约定，不验证网页原文、语义相关性、用户身份、引文真实性或结论质量。合成测试数据明确标记，不能当作研究发现。

## 两次独立离线行为试用

另一 Agent 读取技能与参考文件，在无浏览工具、无外部动作的限定下处理两个请求。原始输入与实际回答见 [行为试用记录](behavior-smoke.md)。

| 场景 | 观察结果 |
| --- | --- |
| 中国小微餐馆排班，仅提供英文工程师搜索摘要与厂商标题 | 保留目标市场，报告证据不足；未虚构原文、链接、搜索次数或需求规模 |
| 剪辑反馈工具，包含同作者转载、现有产品功能和创始人推广 | 去除重复经验、区分厂商功能与客户价值、标记推广，保留付费与效果未知 |

试用发现：允许分析离线材料，但网页 JSON 台账要求 URL，可能导致导出规则不清。
发布前已澄清：无链接的用户提供材料使用标注来源的表格；不编造 URL；合成场景的推断不当作现实验证。详见 SKILL.md 与 evidence-rules.md。

修正后又独立复跑了第二个场景，确认无链接材料可以按标注表格处理，未观察到该歧义再次出现。见 [复查实际输出](behavior-smoke-retest.md)。

这些是有限范围的行为检查，没有无技能基线、多模型比较、重复抽样或统计显著性评测。

## 开发期间的真实检索案例

[剪辑客户反馈研究](../examples/video-feedback/report.zh-CN.md)包含 5 条实际查询、11 次页面读取、8 个打开的唯一页面、7 个入选来源。它用于展示证据记录和决策方式，不是技能效果的独立验证。

查询日志保留了实际使用的字符串，包括未正确写成 site: 的早期查询；没有把改进后的查询伪装成已经执行。示例记录目标匹配不完整、旧资料、推广来源、相对日期差异及竞品覆盖不足。
